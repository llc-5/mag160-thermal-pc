推送到 GitHub
=============

本目录已经是一个完整的 Git 仓库（已 git init，master 分支，已提交）。
目标库：https://github.com/llc-5/mag160-thermal-pc

建议先把该库设成 Private —— mag160-thermal-pc.bundle 里含从 APK 解出的原厂私有产物。


一、推送（在 PowerShell 或 cmd 里执行）
---------------------------------------

    cd C:\Users\18383\Desktop\MAG160-0
    git remote add origin https://github.com/llc-5/mag160-thermal-pc.git
    git push -u origin master:main

如果之前加过 remote，用这个替换：

    git remote set-url origin https://github.com/llc-5/mag160-thermal-pc.git


二、第一次 push 会弹窗要凭据
---------------------------

    Username = llc-5
    Password = Personal Access Token（不是登录密码）

Token 生成地址：https://github.com/settings/tokens
    Generate new token (classic)  ->  勾选 repo  ->  生成（ghp_ 开头的字符串）


三、没进去的东西（体积超限，需要另外分发）
-----------------------------------------

    MagViewerPC_v7/                412MB  主程序本体
    MAG160热像仪-单文件.exe        157MB  便携版（GitHub 单文件硬限制 100MB）
    CheckDevice/                    63MB  USB 诊断工具

这三项都能用 mag160-pc 源码里的 release.py 一条命令重建，见 README.md。
要直接分发的话走 GitHub Releases 附件，或者网盘。


四、源码在哪
-----------

mag160-thermal-pc.bundle 是 mag160-pc 源码仓库的完整打包（14 次提交）。

    git clone mag160-thermal-pc.bundle mag160-pc
